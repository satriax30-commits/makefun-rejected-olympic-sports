One funny single-line sport the Olympics rejected: the queue-jump sprint final — 8 finalists, 1 checkout, and defending champion Lars vaulting a pensioner, a pram and the last basket, only to lose to a man carrying 12 items or fewer. A made-up event real enough to sound like a broadcast, absurd enough to be funny, in 170 characters.

## Run it

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (pass a different path as the first argument to write elsewhere). Node 22 only, standard library only, deterministic — no clock, no randomness, no network.
